# Edufeedia Security Threat Model & Defense Matrix 🛡️

## 1. Scope & Trust Boundaries

Edufeedia protects minor learners, educational data, parental privacy, and curriculum integrity.

| Threat Category | Potential Attack Vector | Applied Mitigation Strategy | Source Reference |
| :--- | :--- | :--- | :--- |
| **Account Takeover** | Credential stuffing, stolen tokens | Argon2/Bcrypt password hashing, short-lived JWTs (60 min), token revocation blacklist in Redis | `app.core.security` |
| **Insecure Direct Object Reference (IDOR)** | Malicious parent/student attempting to access peer student records | Centralized `AccessPolicy.can_view_student_data` enforcing verified relationships | `app.core.access_policy` |
| **Cross-School Tenant Spill** | School Admin A querying or modifying School B records | Explicit `school_id` tenant filters on all queries and 403 Forbidden boundaries | `app.routers.admin`, `app.routers.privacy` |
| **Adversarial Prompt Injection** | System jailbreaks, DAN prompts, instruction overriding | Multi-heuristic injection scoring and regex filter running prior to RAG retrieval | `app.safety.prompt_injection` |
| **Unsafe / Toxic AI Output** | Hallucinations or inappropriate content generated by LLM | Fail-closed post-generation safety classification across 6 categories | `app.safety.engine`, `app.ai.model_gateway` |
| **Fake Guardian Consent** | Malicious student forging parent email OTP | Time-limited (10 min) cryptographically random 6-digit OTP stored with single-use Redis TTL | `app.routers.privacy` |
| **OTP Brute Force** | High-velocity OTP trial attack | Max 5 failed attempts per OTP lifecycle; Redis sliding-window rate limit (3 req/min) | `app.routers.privacy` |
| **Public Role Escalation** | Registration payload specifying `role: "school_admin"` | Public registration endpoint strictly forces `role="student"`; staff requires admin invite | `app.routers.auth` |
| **Malicious Content Ingestion** | Ingesting toxic third-party video or web link | Pre-ingestion safety audit, domain whitelist, SHA-256 deduplication, educator review gate | `app.ingestion.intelligence_pipeline` |
| **XP Farming Concurrency Exploit** | Rapid parallel quiz submission to farm leaderboard XP | Database unique constraint `uq_student_quiz_attempt` and first-attempt-only XP logic | `app.routers.quiz` |

## 2. Fail-Closed Safety Guarantees

In accordance with strict safety requirements for minors:
- If the AI safety classifier fails to execute, the system **fails closed**: the response is blocked, logged, and substituted with an educational redirect message.
- If external LLMs (OpenAI, Gemini) experience service degradation or timeouts, the Model Gateway falls back to curated local curriculum responses without disrupting the student session.
